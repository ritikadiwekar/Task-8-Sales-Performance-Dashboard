# 📊 Sales Performance Dashboard (Power BI)

## 📖 Project Description

This project is an interactive **Sales Performance Dashboard** built using **Power BI**. It provides insights into sales performance by analyzing key business metrics such as Total Sales, Total Profit, Total Orders, Profit Margin, Sales by Region, Sales by Category, and Monthly Sales Trends. Interactive slicers allow users to filter data by Region and Category for better analysis.

---

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel (CSV Dataset)

---

## 📌 Dashboard Features

- 📈 Total Sales KPI
- 💰 Total Profit KPI
- 📦 Total Orders KPI
- 📊 Profit Margin (%)
- 🌍 Sales by Region
- 🥧 Sales by Category
- 📅 Monthly Sales Trend
- 🎯 Region Slicer
- 🎯 Category Slicer

---

## 💡 Key Insights

- West region generated the highest sales.
- Technology category contributed the highest share of sales (36%).
- Sales showed an overall upward trend towards the end of 2017.
- The business achieved **2.30M Total Sales**, **286.40K Profit**, and **12.5% Profit Margin**.
